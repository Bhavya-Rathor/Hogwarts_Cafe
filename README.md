# Hogwarts Cafe ☕✨

A modern, responsive, high-converting 1-page website designed for **Hogwarts Cafe** (Artisan Bakery & Specialty Coffee).

## ✨ Features
- **Luxury Aesthetic:** Tailored warm cafe theme built with Tailwind CSS & Google Fonts (Playfair Display + Plus Jakarta Sans).
- **Interactive Digital Menu:** Filterable categories (Coffee, Bakery, Brunch) with high-res photos and ingredient details.
- **Smart Order List & Multi-Item Cart:**
  - Add multiple items to order list
  - Real-time badge counter
  - Adjust quantities (+ / -) or remove items
  - Generates a **Unique Order ID** (e.g. `#HW-4821`)
  - Direct 1-tap checkout via WhatsApp with structured order summary
- **Table Reservation Modal:** WhatsApp-connected table reservation system.
- **Customer Reviews & Social Proof:** Testimonials with Google Star ratings.
- **Location, Hours & Google Maps Embed:** Clean directions and direct contact.
- **100% No-Database Required:** Runs as a static web app with zero backend maintenance costs.

## 🚀 Live Demo
Easily deployable on [Netlify](https://app.netlify.com/drop) or GitHub Pages.
